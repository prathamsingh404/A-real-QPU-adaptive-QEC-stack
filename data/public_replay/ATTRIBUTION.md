# Google Quantum AI memory experiments

Google Quantum AI, *Data for “Quantum error correction below the surface code threshold”*, version 1.0.0 (2024). The files in the google_105Q_surface_code_d3_d5_d7 directory are unmodified members of the authors' archive. Attribution and licensing for this dataset are separate from the repository's MIT software license. [Dataset and license](https://zenodo.org/records/13273331) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

The retained subset contains detector events, actual observable flips, SI1000 circuit, metadata and the authors' correlated-matching predictions for both bases of the d3_at_q4_5 patch at 13 rounds. The README inside the directory is the authors' data-format documentation. The first 6,000 rows in each basis are reserved for calibration. The same remaining 44,000 rows are scored at both window sizes. The two analyses of a given basis reuse measurements.

An additional comparison uses the publisher's Harmony predictions under SI1000 and optimized priors, plus its correlated predictions under the optimized prior. These files are unmodified source members. The publisher reports training the optimized priors using 13-cycle calibration data. Independence from these same-round records is unverified.
