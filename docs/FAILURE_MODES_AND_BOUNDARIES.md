# Known limits

A shift that preserves detector marginals can escape the alarm. A stale reference can trigger updates on benign differences. Short windows give noisy edge estimates, and an abrupt change can end before an updated graph is used. A shared maximum allows different realized work. Multiple windows from a single stream are dependent. Two public files from one placement cannot characterize drift across devices. A CPU benchmark omits acquisition and feedback. The full panel outcomes and uncertainty are in the [ledger](../VALIDATION.md).
