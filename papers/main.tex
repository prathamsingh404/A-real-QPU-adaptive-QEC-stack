\title{When should a surface-code decoder rebuild its matching graph?\\ \large A paired benchmark under a fixed update cap}
\author{Pratham Singh\\ \small Internal research draft}

\begin{abstract}
We test whether syndrome-triggered reweighting improves memory decoding when the decoder may rebuild its graph at most twice. Seven causal policies and a privileged diagnostic reference score the same simulated observations. Across 30 independently seeded distance-three Z-memory hotspot trajectories, selective updating made 6,406 errors versus 6,460 for periodic updating in 360,000 shots. The paired difference was $-0.015$ percentage points (95\% CI $[-0.034,0.004]$; Holm-adjusted $p=0.337$). It fell below our predefined minimum useful improvement of 0.060 percentage points. The selective policy used 30 rebuilds versus 60. A separately frozen, one-fit follow-up on 90 fresh distance-three seeds found a smaller-than-target benefit against a trained calendar ($-0.0129$ percentage points, $p=0.00460$). A correlated-matching follow-up tested a library of known local faults. Flexible selection saved 190 errors in 768,000 simulated shots relative to a trained calendar, with a gain below the same practical threshold. It tied factory decoding on 384,000 measured Willow shots and added 1,855 errors across 800,000 shots in a separate ordered acquisition series. These experiments identify when simulated gains fail to transfer.
\end{abstract}

\section{Question and relation to previous work}
Updating a matching decoder using syndrome correlations predates this experiment. Spitz et al.\ inferred physical errors from syndrome changes \cite{spitz}. The decoding graph reweighting (DGR) study estimated edge probabilities and introduced correlation-aware decoding \cite{dgr}. Bhardwaj et al.\ studied tracking drifting error rates over time \cite{bhardwaj}; ReloQate links detector fire rates to logical error and remaps patches for recalibration \cite{relo}. Recent neural and hardware approaches further narrow the claim. NVIDIA Ising learns local corrections and also considers learning weights from syndromes \cite{ising}. Google demonstrated physical control of QEC under injected drift \cite{googlecontrol}. QAdapt studies continual adaptation of a neural predecoder with Willow evaluation \cite{qadapt}. IBM Relay-BP changes the decoder inference algorithm \cite{relay}. Our comparison concerns the timing and number of rebuilds with a shared estimator. We do not compare full implementations of these published algorithms. The analysis protocol and simulation code were frozen internally before the evaluation seeds ran. Design choices followed an earlier exploratory study.

\section{Methods}
Stim generates rotated surface-code memories with rounds equal to code distance. Each simulated trajectory has a 6,000-shot independent nominal reference and 60 blocks of 200 evaluation shots. Four regimes cover stationary noise, a uniform ramp, transient local hotspots and a bias change. Disturbed trajectories randomize onset and duration, and hotspot targets and amplitudes vary across seeds. Local error channels occur throughout the flattened circuit. A block represents independent executions of a memory under one noise law. The model changes between blocks. We sample 30 Z-memory seeds at distance 3, 12 at distance 5, six at distance 7, and ten X-memory seeds at distance 3 per regime. The two analysis windows reuse each stream. In total there are 2,784,000 distinct evaluation shots.

All deployable arms decode with the current graph before reading the completed window for updates. The first window uses factory weights. Updates use unlabeled detector patterns. The empirical estimator maps detector parity correlations onto existing matching edges while preserving their boundary and observable labels. Shrinkage averages empirical and factory edge probabilities. The rolling comparator pools two windows. The periodic and selective comparators share this shrinkage weight and a cap of two rebuilds. Periodic updating fits at one-third and two-thirds of the trajectory. Selective updating fits on entering an alarm, retains the graph during a sustained alarm, and restores the factory graph on clearance. Alarms compare detector counts against the independent reference using twice the smaller conditional hypergeometric tail, with Bonferroni correction across detectors and planned looks. This calibrates false alarms under independent identically distributed shots under the null. It provides no bound on logical error. A historical heuristic is included with the same causal scoring order. A privileged reference uses the current generating circuit's matching graph.

The primary endpoint is selective minus periodic logical error rate (LER) at distance three, Z basis, hotspot regime, window 2,000. Inference uses independent trajectories as units, paired two-sided $t$ tests and Holm correction across the four primary-panel regimes. Pointwise intervals describe mean differences. Success also requires a hotspot improvement of at least 0.0006 absolute and a one-sided stationary upper bound versus factory below the same margin. Remaining contrasts are descriptive.

\subsection*{Independent test of update timing}
After a post hoc timing analysis (Supplement), we froze a new protocol and a stronger comparator before opening a second set of simulation seeds. Both arms rebuilt exactly once, used identical shrinkage, and retained the new graph for precisely one window. The alarm arm used the first significant look, with a forced fit at the final opportunity. The calendar used the time with the lowest development-set LER among all five opportunities. The earliest tie won. Both distances selected an update after window two. The new primary panel used 90 fresh distance-three Z-memory hotspot trajectories. The nominal reference and noise law followed the original design. A second panel used 45 fresh distance-five trajectories.

At distance three the alarm made 20,025 errors versus 20,164 for the trained calendar in 1,080,000 shots. The paired difference was $-0.01287$ percentage points (95\% CI $[-0.02167,-0.00407]$, two-sided $p=0.00460$, signed-rank $p=0.000206$). The policies chose the same time in 72 trajectories. Among the other 18, the alarm won 16 and lost two. At distance five the counts were 5,257 versus 5,313 in 540,000 shots (difference $-0.01037$ points, descriptive). The evidence supports a small timing effect under this simulated onset distribution. The follow-up's predefined useful improvement was 0.060 percentage points and the primary interval excludes that magnitude.

\section{Experimental replay and cost}
We replay two public Google distance-three memory records (X and Z, 13 rounds, one placement) \cite{google}. For each basis the first 6,000 shots calibrate the alarm and the remaining 44,000 score all policies. File order defines the split. The files do not establish chronological drift or independent devices. Comparison with the publisher's predictions uses identical held-out labels.

\section{Correlated matching and transfer across acquisitions}
A third internally frozen design retained decomposition and logical labels when changing detector-error-model priors. One policy selected factory, locally adjusted, or globally adjusted priors using held-out detector marginals from within the preceding window. Another selected from a library consisting of factory and one graph per data qubit, each modeling a two-percent depolarizing channel at every circuit tick. The library therefore knows the family used to generate simulated hotspots. Both policies were capped at two active next windows. Each comparator used the same model family with two calendar opportunities selected on development data. Window size was 1,000 complete memory shots. Each trajectory comprised eight windows. The primary panel pooled 24 independent trajectories per stationary, abrupt, gradual and recurring condition at distance three. Distance five and uniform and biased shifts were transfer checks. The development-only hindsight maximum among the enumerated two-use empirical updates was 103 fewer errors than factory in 256,000 shots.

The empirical policy made 11,849 errors against 11,878 for its calendar (Holm $p=0.303$). The library made 11,386 errors versus 11,576 for its calendar. The difference was $-0.02474$ percentage points (95\% CI $[-0.03801,-0.01146]$, Holm $p=0.000723$). It used a nonfactory model for 144 windows versus 65 for its calendar. This contrast measures scheduling flexibility under a common cap. Aggregate online CPU times were 1.428 and 1.461 seconds, excluding setup and transport. Neither policy met all three specified criteria for accuracy, statistical evidence and time. The budgeted library also increased errors relative to factory for uniform and biased shifts at both distances.

On four ten-cycle Willow records from two patches and both bases \cite{willowdata}, the library selected factory at every opportunity. It made 26,346 errors in 384,000 scored physical shots. The released sparse-blossom, SI1000 Tesseract, frequency-calibrated Tesseract and AlphaQubit~2 predictions gave 23,408, 21,138, 20,094 and 18,632. The fixed-SI1000 Tesseract alone shows a substantial gap. These are file-order comparisons without acquisition timestamps.

An exploratory forward test used acquisition samples 13--20 from the 72-qubit set~1 release \cite{google,hoyt}. For each of two bases at one distance-three patch, interleaving divided each 50,000-shot acquisition into 50 disjoint batches of 1,000. A decision trained on acquisition $j$ was applied to its corresponding batch in $j+1$. The batches share device conditions. The budgeted library made 27,779 X and 24,777 Z errors versus 26,819 and 23,882 under factory; the same-library calendar stayed at factory. Released SI1000 Harmony predictions made 23,808 and 20,865 errors. The empirical selective policy made 26,870 and 23,832. A post hoc check found lower or equal marginal composite likelihood than factory on 96 of 115 active library windows in the deployment acquisition. Those windows accounted for 1,532 excess errors. The other 19 accounted for another 323 despite higher marginal likelihood. The evidence points to both poor persistence and limitations of the selection objective.

Prior work already estimates drifting noise and adapts decoding. Darmawan quantified the importance of characterizing local noise \cite{darmawan}; Schwartzman-Nowik et al.\ learned additional correlated fault mechanisms and evaluated them on physical data \cite{augment}. Our evidence concerns a specific decision under constrained update opportunities and the conditions under which its gains disappear.

\section{Interpretation and limitations}
Selective updating used fewer rebuilds than periodic updating in the primary panel. Equal caps permit unequal realized work, and an always-on monitor has its own cost. The primary interval includes zero and excludes an improvement as large as the specified minimum. This experiment gives no evidence of generic superiority, a threshold shift or closed-loop hardware performance. The noise model omits leakage and realistic temporal correlations within shots; the secondary panels have few independent seeds. Reference-window contamination and realistic accelerator deadlines deserve separate tests. The most informative follow-up would hold the method fixed and compare with independently implemented drift-tracking decoders on timestamped, repeated acquisitions.

\section*{Supplement: separating rebuild timing from graph retention}
A reviewer could reasonably ask whether the comparison changes if every trajectory does exactly the same number of rebuilds. All 30 selective hotspot trajectories in the primary panel used one fit. After examining that result, we replayed those streams with one fixed midpoint fit. We verified the factory error count in every regenerated window before scoring the alternatives. The estimator, reference graph and memory shots were identical. Two retention rules tested whether an update could remain useful after recovery. Every variant used precisely one fit per trajectory.

All variants reuse the primary evaluation data and the additional contrasts were chosen afterward. They motivated the independent timing test in Section 3.

\section*{Supplement: implementation and interpretation}
The nominal circuit uses a channel probability of 0.004 for after-Clifford, reset, measurement and before-round data faults in Stim's memory generator. An active hotspot inserts a local depolarizing channel of 0.02 or 0.04 at each tick; the bias condition inserts a Z channel of 0.002 or 0.005 on data qubits. The uniform disturbance ramps toward 0.006 or 0.008. Onsets are uniform on block indices 12--20 and durations on 16--28 inclusive. An independent reference is sampled for each trajectory. The trigger tests individual detector marginals, so a pure correlation change can be invisible. The reported detector-model match has access to the simulator's changing noise law; it is a diagnostic reference for matching.

One full fit and one cached reset have different host costs. Timing uses serial CPU-side wall-clock measurements after three warmups, with 30 trials per requested path. Previously active graphs in the reset benchmark are built from independent disturbed samples before timing. The recorded action labels identify the actual branches taken. Input acquisition, calibration sampling and prediction labels lie outside the timed interval. A reduction in rebuild count by itself cannot establish a reduction in total compute or feedback latency.
