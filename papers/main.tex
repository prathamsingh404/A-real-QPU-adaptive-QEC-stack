\begin{abstract}
We test whether syndrome-triggered reweighting improves memory decoding when the decoder may rebuild its graph at most twice. Seven causal policies and a privileged diagnostic reference score the same simulated observations. Across 30 independently seeded distance-three Z-memory hotspot trajectories, selective updating made 6,406 errors versus 6,460 for periodic updating in 360,000 shots. The paired difference was $-0.015$ percentage points (95\% CI $[-0.034,0.004]$; Holm-adjusted $p=0.337$). It fell below our predefined minimum useful improvement of 0.060 percentage points. The selective policy used 30 rebuilds versus 60. On two public experimental memory records the publisher's correlated decoder outperformed every policy tested here. These results quantify a cost and accuracy tradeoff and leave the superiority hypothesis unresolved.
\end{abstract}

\section{Question and relation to previous work}
Updating a matching decoder using syndrome correlations predates this experiment. Spitz et al.\ inferred physical errors from syndrome changes \cite{spitz}. The decoding graph reweighting (DGR) study estimated edge probabilities and introduced correlation-aware decoding \cite{dgr}. Bhardwaj et al.\ studied tracking drifting error rates over time \cite{bhardwaj}; ReloQate links detector fire rates to logical error and remaps patches for recalibration \cite{relo}. Our comparison concerns the timing and number of rebuilds with a shared estimator. We do not compare full implementations of these published algorithms. The analysis protocol and simulation code were frozen internally before the evaluation seeds ran. Design choices followed an earlier exploratory study.

\section{Methods}
Stim generates rotated surface-code memories with rounds equal to code distance. Each simulated trajectory has a 6,000-shot independent nominal reference and 60 blocks of 200 evaluation shots. Four regimes cover stationary noise, a uniform ramp, transient local hotspots and a bias change. Disturbed trajectories randomize onset and duration, and hotspot targets and amplitudes vary across seeds. Local error channels occur throughout the flattened circuit. A block represents independent executions of a memory under one noise law. The model changes between blocks. We sample 30 Z-memory seeds at distance 3, 12 at distance 5, six at distance 7, and ten X-memory seeds at distance 3 per regime. The two analysis windows reuse each stream. In total there are 2,784,000 distinct evaluation shots.

All deployable arms decode with the current graph before reading the completed window for updates. The first window uses factory weights. Updates use unlabeled detector patterns. The empirical estimator maps detector parity correlations onto existing matching edges while preserving their boundary and observable labels. Shrinkage averages empirical and factory edge probabilities. The rolling comparator pools two windows. The periodic and selective comparators share this shrinkage weight and a cap of two rebuilds. Periodic updating fits at one-third and two-thirds of the trajectory. Selective updating fits on entering an alarm, retains the graph during a sustained alarm, and restores the factory graph on clearance. Alarms compare detector counts against the independent reference using twice the smaller conditional hypergeometric tail, with Bonferroni correction across detectors and planned looks. This calibrates false alarms under independent identically distributed shots under the null. It provides no bound on logical error. A historical heuristic is included with the same causal scoring order. A privileged reference uses the current generating circuit's matching graph.

The primary endpoint is selective minus periodic logical error rate (LER) at distance three, Z basis, hotspot regime, window 2,000. Inference uses independent trajectories as units, paired two-sided $t$ tests and Holm correction across the four primary-panel regimes. Pointwise intervals describe mean differences. Success also requires a hotspot improvement of at least 0.0006 absolute and a one-sided stationary upper bound versus factory below the same margin. Remaining contrasts are descriptive.

\section{Experimental replay and cost}
We replay two public Google distance-three memory records (X and Z, 13 rounds, one placement) \cite{google}. For each basis the first 6,000 shots calibrate the alarm and the remaining 44,000 score all policies. File order defines the split. The files do not establish chronological drift or independent devices. Comparison with the publisher's predictions uses identical held-out labels.

\section{Interpretation and limitations}
Selective updating used fewer rebuilds than periodic updating in the primary panel. Equal caps permit unequal realized work, and an always-on monitor has its own cost. The primary interval includes zero and excludes an improvement as large as the specified minimum. This experiment gives no evidence of generic superiority, a threshold shift or closed-loop hardware performance. The noise model omits leakage and realistic temporal correlations within shots; the secondary panels have few independent seeds. Reference-window contamination and realistic accelerator deadlines deserve separate tests. The most informative follow-up would hold the method fixed and compare with independently implemented drift-tracking decoders on timestamped, repeated acquisitions.

\section*{Supplement: separating rebuild timing from graph retention}
A reviewer could reasonably ask whether the comparison changes if every trajectory does exactly the same number of rebuilds. All 30 selective hotspot trajectories in the primary panel used one fit. After examining that result, we replayed those streams with one fixed midpoint fit. We verified the factory error count in every regenerated window before scoring the alternatives. The estimator, reference graph and memory shots were identical. Two retention rules tested whether an update could remain useful after recovery. Every variant used precisely one fit per trajectory.

All variants reuse the primary evaluation data and the additional contrasts were chosen afterward. They require prospective replication before they can support a general improvement claim.

\section*{Supplement: implementation and interpretation}
The nominal circuit uses a channel probability of 0.004 for after-Clifford, reset, measurement and before-round data faults in Stim's memory generator. An active hotspot inserts a local depolarizing channel of 0.02 or 0.04 at each tick; the bias condition inserts a Z channel of 0.002 or 0.005 on data qubits. The uniform disturbance ramps toward 0.006 or 0.008. Onsets are uniform on block indices 12--20 and durations on 16--28 inclusive. An independent reference is sampled for each trajectory. The trigger tests individual detector marginals, so a pure correlation change can be invisible. The reported detector-model match has access to the simulator's changing noise law; it is a diagnostic reference for matching.

One full fit and one cached reset have different host costs. Timing uses serial CPU-side wall-clock measurements after three warmups, with 30 trials per requested path. Previously active graphs in the reset benchmark are built from independent disturbed samples before timing. The recorded action labels identify the actual branches taken. Input acquisition, calibration sampling and prediction labels lie outside the timed interval. A reduction in rebuild count by itself cannot establish a reduction in total compute or feedback latency.
